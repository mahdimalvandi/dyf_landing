# DYF (Defender Your Foot) — Private B2B Catalog & Luxury Brand Platform

پلتفرم یکپارچه معرفی برند، پنل مدیریت کارگاهی و کاتالوگ خصوصی B2B برند کفش چرم دست‌دوز **DYF (Defender Your Foot)**، طراحی و توسعه داده‌شده بر پایه **دیزاین سیستم DYF v4** با رویکرد اشرافی (Luxury Atelier) و ساختار Vanilla JavaScript بدون وابستگی به فریم‌ورک‌های سنگین.

---

## ساختار صفحات و معماری پروژه

| مسیر صفحه | شرح عملکرد | دسترسی و فناوری |
| :--- | :--- | :--- |
| `index.html` | صفحه فرود اصلی برند (Landing Page) | ویترین عمومی، داستان کارگاه، مدل سه‌بعدی تعاملی نشان کارگاه (GLB Model Viewer)، فرم ارتباط و گالری تولیدات |
| `admin.html` | پنل مدیریت کاتالوگ خصوصی (Admin Panel) | داشبورد تحلیلی، مدیریت مدل‌های کفش با صفحه‌بندی، مدیریت لاین‌ها و دسته‌ها، مدیریت بنکداران و مشتریان، ویزارد ۵ مرحله‌ای صدور لینک و کیت کامپوننت‌ها |
| `catalog.html` | کاتالوگ اختصاصی خریداران و بنکداران (B2B Showcase) | ورود دومرحله‌ای پیامکی (OTP) و ورود مستقیم با لینک توکن‌دار، تایمر شمارش معکوس نشست پایدار، فیلتر هوشمند محصولات بر اساس قواعد دسترسی و شناسنامه تخصصی محصول |

## نحوه راه‌اندازی و اجرای محلی (Local Server)

برای تجربه کامل فونت‌ها، تصاویر و شبیه‌سازی نشست‌ها، پروژه را با یک وب‌سرور سبک لوکال اجرا نمایید:

```bash
# اجرای سرور با پایتون
python -m http.server 8000
```

سپس در مرورگر نشانی‌های زیر را باز فرمایید:
- **صفحه فرود برند:** `http://localhost:8000/index.html`
- **پنل مدیریت کارگاه:** `http://localhost:8000/admin.html`
- **کاتالوگ اختصاصی خریدار:** `http://localhost:8000/catalog.html`

## ساختار پوشه‌ها و دارایی‌ها (Assets)

```text
dyf_landing/
├── admin.html                 # پنل تک‌صفحه‌ای مدیریت (SPA)
├── catalog.html               # رابط کاربری کاتالوگ خصوصی خریداران
├── index.html                 # لندینگ پیج و معرفی برند
├── DESIGN.md                  # توکن‌های رنگی، تایپوگرافی و قواعد بصری v4
├── docs/
│   ├── design/adminPanel.md   # مستندات و تسک‌های ۷ گانه طراحی پنل
│   └── product/docs.md        # قوانین محصول، پرسونای مخاطب و معماری دسترسی
└── assets/
    ├── css/
    │   ├── admin.css          # استایل‌های دیزاین سیستم، پنل و کامپوننت‌ها
    │   ├── catalog.css        # استایل‌های لوکس کاتالوگ خریدار و تایمر نشست
    │   └── style.css          # استایل‌های صفحه فرود اصلی
    ├── js/
    │   ├── admin.js           # منطق کنترلرها، روتر، ویزارد و ذخیره‌سازی محلی
    │   ├── catalog.js         # احراز هویت خریدار، فرمول دسترسی و تایمر کاتالوگ
    │   ├── model-viewer.min.js# رندر فایل سه‌بعدی نشان کارگاه
    │   └── script.js          # تعاملات و انیمیشن‌های صفحه فرود
    ├── images/                # عکس‌های آتلیه‌ای و باکیفیت کفش‌های دست‌دوز
    └── models/                # فایل‌های مدل سه‌بعدی GLB
```
