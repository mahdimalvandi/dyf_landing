# بخش جزئیات، پیش از محصول

- چیدمان اصلی حفظ شده: یک نمای بزرگ کنار دو نمای جزئیات؛ روی موبایل هر سه قاب عمودی‌اند تا تصاویر و عنوان‌ها کوچک نشوند.
- طبق بازخورد مالک، زمینهٔ تصویری قبلی حفظ شد؛ دور قاب‌ها خط طلایی و حاشیهٔ ظریف شبیه دوخت، جداکنندهٔ شماره‌ها و خط پایانی اضافه شدند. نوشته‌های انگلیسی تکراری حذف مانده‌اند؛ رنگ‌ها و فونت موجود برند حفظ شده‌اند.
- تصاویر جزئیات، برش CSS از همان عکس فعلی `frontend/assets/images/shoes.jpeg` هستند؛ عکس ماکرو یا عکس واقعی تولید DYF معرفی نمی‌شوند. فایل و وابستگی جدیدی اضافه نشده است.
- تصاویر کیف جایگزین شدند. عنوان‌ها و altها فقط محتوای قابل مشاهده را توصیف می‌کنند و ادعای چرم طبیعی یا دست‌دوزبودن ندارند.
- پیش از انتشار، عکس اصلی و دو عکس نزدیک واقعی از همان مدل با تأیید مالک جایگزین شوند؛ برش عکس فعلی جای عکاسی جزئیات را نمی‌گیرد.
