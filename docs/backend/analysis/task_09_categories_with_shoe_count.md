# سند تحلیل فنی تسک ۹: دسته‌بندی‌ها به همراه شمارنده مدل‌های کفش (Categories with Shoe Count)
**مسیر سند:** `docs/backend/analysis/task_09_categories_with_shoe_count.md`  
**وضعیت:** پیاده‌سازی‌شده (Implemented)  
**نسخه:** ۱.۰  

---

## ۱. هدف و چشم‌انداز محصولی (Product Vision & Goals)

در صفحه مدیریت مدل‌های کفش پنل ادمین (و تب‌های فیلتر محصولات)، مدیر کارگاه نیاز دارد بداند در هر لاین محصول دقیقاً چه تعداد کفش ثبت شده است؛ به عنوان مثال: «کفش رسمی (۱۲)»، «کالج و لوفر (۵)»، «بوت و نیم‌بوت (۰)».  
هدف این تسک، ارائه فهرست دسته‌بندی‌ها به همراه شمارنده مدل‌های کفش متعلق به هر دسته (`shoeCount`) است تا فرانت‌اند بتواند در تب‌های بالای فهرست محصولات یا دراپ‌داون‌های فیلتر، تعداد مدل‌ها را روبروی هر لاین نمایش دهد.

---

## ۲. تحلیل پایگاه داده (Database Analysis)

از آنجایی که در جدول `"shoeModels"` آرایه دسته‌بندی‌ها در فیلد `"categoryIDs"` به صورت JSONB ذخیره می‌شود و دارای ایندکس GIN است:
- هیچ نیازی به تغییر ساختار جداول یا افزودن ستون جدید به دیتابیس نیست (Zero Migration Overhead).
- شمارش تعداد کفش‌های هر دسته با استفاده از کوئری استاندارد با شرط مقایسه جی‌سان (`s."categoryIDs" @> jsonb_build_array(c."ID")`) به صورت زنده و بلادرنگ استخراج می‌شود.

---

## ۳. طراحی روت‌ها و قرارداد APIها (API Contracts)

### اندپوینت‌های مربوطه:
1. **فهرست دسته‌بندی‌ها (`GET /api/v1/categories`):**  
   خروجی شامل آرایه‌ای از دسته‌بندی‌ها است که هر آبجکت علاوه بر `ID` و `title`، فیلد `shoeCount` (تعداد کل کفش‌های فعال منتسب به آن دسته) را بازمی‌گرداند.
2. **جزییات دسته‌بندی (`GET /api/v1/categories/:id`):**  
   اطلاعات دسته‌بندی به همراه `shoeCount` بازگردانده می‌شود.

#### ساختار پاسخ:
```json
{
  "success": true,
  "statusCode": 200,
  "message": "فهرست دسته‌بندی‌ها با موفقیت دریافت شد",
  "data": [
    {
      "ID": 1792757059582788000,
      "title": "کفش رسمی دست‌دوز",
      "shoeCount": 12
    },
    {
      "ID": 1792757059584828900,
      "title": "کالج و لوفر",
      "shoeCount": 5
    }
  ],
  "meta": null
}
```

## ۴. معماری لایه‌بندی و تغییرات کد

1. **`internal/dto/category/response.go`:** اضافه شدن فیلد `ShoeCount int64` به `CategoryResponse`.
2. **`internal/entity/category/entity.go`:** تعریف استراکت `CategoryWithCount` جهت اسکن مستقیم کوئری تجمیعی.
3. **`internal/repository/category/repository.go`:**
   - متد `ListCategoriesWithShoeCount()`: استخراج دسته‌بندی‌ها به همراه شمارنده کفش‌ها در یک کوئری سریع.
   - متد `CountShoesForCategory(categoryID int64)`: شمارش تعداد کفش‌های یک دسته‌بندی تکی.
4. **`internal/service/category/`:**
   - به‌روزرسانی `list.go` جهت استفاده از متد کوئری شمارنده‌دار.
   - به‌روزرسانی `detail.go` و `update.go` و `create.go` جهت مقداردهی صحیح `ShoeCount`.
