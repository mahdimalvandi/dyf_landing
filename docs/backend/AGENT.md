# راهنمای جامع ایجنت‌های هوش مصنوعی (AI AGENT PLAYBOOK)
**پروژه:** DYF Private Catalog Backend  
**مخاطب:** هر دستیار هوش مصنوعی و مدل زبانی (LLM) که در این پروژه وظیفه توسعه کد، بازبینی یا عیب‌یابی دارد.

---

## ۱. اصول رفتاری و قوانین غیرقابل‌تغییر برای Agent

هنگام کار بر روی این پروژه، الزامات زیر باید به صورت ۱۰۰٪ و بدون استثنا رعایت شوند:

1. **نسخه زبان و فریمورک:**
   - زبان برنامه‌نویسی: **Go 1.26**
   - وب‌فریمورک: **Fiber v3** (`github.com/gofiber/fiber/v3`)
   - کتابخانه جیسون: **jsoniter** (`github.com/json-iterator/go`)
   - ابزار مایگریشن: **golang-migrate** (`github.com/golang-migrate/migrate/v4`)

2. **قانون ممنوعیت کامنت (Zero Comments):**
   - در هیچ فایل کدی در پوشه `backend/` نباید هیچ‌گونه کامنتی (`//` یا `/* */`) درج شود.

3. **قانون ممنوعیت متغیرهای تک‌حرفی (No Single-Letter Variables):**
   - نام تمامی متغیرها باید کاملاً توصیفی باشد (مثلاً `fiberContext` به جای `c`، `customerRepo` به جای `r`، `validationError` به جای `e`).
   - تنها استثنا: شمارنده‌های ایندکس حلقه (`index` یا `i`).

4. **قانون نام‌گذاری و اختصارات (Strict camelCase & Capitalized Initialisms):**
   - تمامی نام‌گذاری‌ها در JSON، متغیرها، ستون‌های دیتابیس و جداول با camelCase است.
   - کلیه اختصارات فنی باید تمام‌بزرگ باشند: `categoryID`, `shoeID`, `customerID`, `adminID`, `primaryImageURL`, `clientIP`, `verifyOTP`, `tokenMD5`.

5. **قانون پوینترها (Value-Type Policy):**
   - تا جای ممکن از ساختارهای مقداری (Value) استفاده کنید و از تعریف پوینترهای غیرضروری پرهیز کنید تا ریسک `nil pointer dereference` از بین برود.

6. **قانون ساختار شناسه و زمان:**
   - فیلد `"ID"` از نوع `int64` (در دیتابیس `bigint`) است و زمان ساخت رکورد به نانوثانیه (`time.Now().UnixNano()`) است.
   - **هیچ فیلدی به نام `createdAt` وجود ندارد.**
   - هیچ فیلد `time.Time` وجود ندارد؛ تمام زمان‌ها `int64` یونیکس هستند.

7. **تگ‌های GORM در Entity:**
   - در Structهای موجودیت‌ها تنها تگ مجاز GORM، تگ `column` است: `gorm:"column:fieldName"`.
   - کلیه محدودیت‌های کلید اصلی، پیش‌فرض، یکتایی و نات‌نال منحصراً در فایل‌های مایگریشن SQL قرار می‌گیرند.

8. **قرارداد ۳ خروجی در Get های ریپازیتوری:**
   - هر متد جستجوی رکورد در ریپازیتوری باید ۳ مقدار برگرداند: `(item, found, error)`.
   - در صورت عدم یافتن: `found = false` و `error = nil`.

9. **مدیریت خطای فارسی:**
   - سرویس و ریپازیتوری ارورهای دامنه را از طریق `apperror.New(...)` یا سنتینل ارورها برمی‌گردانند.
   - لایه پاسخ‌دهی (`response.FromAppError`) با رجوع به مپ خطاها، متن فارسی و Status Code متناظر را در انولوپ JSON تحویل می‌دهد.

10. **احراز هویت توکن‌محور و هش MD5:**
    - به جای JWT، از توکن تصادفی امن Opaque استفاده می‌شود.
    - هش MD5 توکن در جدول دیتابیس ذخیره شده و در اعتبارسنجی هدر `Authorization: Bearer <token>` کوئری می‌شود.

11. **ذخیره‌سازی رسانه‌ها با اینترفیس Storage:**
    - آپلود عکس‌ها و ویدیوها با اینترفیس `StorageService` و پیاده‌سازی لوکال فایل‌سیستم (`./uploads/...`) انجام می‌شود.

12. **تایم‌اوت ۱۰ ثانیه‌ای Context:**
    - میدلور سراسری برای کلیه درخواست‌ها تایم‌اوت ۱۰ ثانیه‌ای روی `context.Context` اعمال می‌کند.

## ۳. فهرست تفصیلی اسناد تسک‌های پیاده‌سازی (Task Specifications)

کلیه تسک‌های پیاده‌سازی بک‌اند به صورت ماژولار و با تمام جزئیات فنی و قراردادهای API در پوشه `tasks/` مستند شده‌اند:

1. **[تسک ۱: احراز هویت توکن‌محور، سرویس OTP و میدلورهای پایه (tasks/01_auth_and_sessions.md)](./tasks/01_auth_and_sessions.md)**
   - ورود پیامکی مدیر و مشتری، تولید هش MD5، جدول `adminTokens`، میدلور احراز هویت و تایم‌اوت ۱۰ ثانیه‌ای.
2. **[تسک ۲: مدیریت دسته‌بندی‌ها و لاین‌های محصول (tasks/02_categories.md)](./tasks/02_categories.md)**
   - لاین‌های همیشه فعال، عنوان فارسی، اسلاگ یکتا، شمارش مدل‌های منتسب و تفکیک ایمن هنگام حذف.
3. **[تسک ۳: مدیریت مدل‌های کفش، گالری مدیا و ذخیره‌سازی فایل (tasks/03_shoe_models_and_media.md)](./tasks/03_shoe_models_and_media.md)**
   - انتشار مستقیم و دائمی، شناسنامه فنی (رنگ، سایز، ویدیو، عکس اصلی)، اینترفیس `StorageService` روی فایل‌سیستم، جستجوی زنده با DYF-ID.
4. **[تسک ۴: مدیریت مشتریان و مجوزهای دسترسی مستقیم (tasks/04_customers_and_direct_access.md)](./tasks/04_customers_and_direct_access.md)**
   - بنکداران B2B، یکتایی شماره همراه، فعال/غیرفعال‌سازی، ماتریس دسترسی مستقیم متصل به پروفایل.
5. **[تسک ۵: صدور و مدیریت لینک‌های دسترسی اختصاصی توکن‌دار (tasks/05_access_links.md)](./tasks/05_access_links.md)**
   - توکن امن غیرقابل‌حدس، روش ورود مستقیم یا پیامکی، ماشین وضعیت لینک‌ها، چرخه‌های زمانی و فعال‌سازی مجدد.
6. **[تسک ۶: موتور کاتالوگ خصوصی، ماتریس دسترسی و سشن‌های زمان‌دار (tasks/06_catalog_and_access_engine.md)](./tasks/06_catalog_and_access_engine.md)**
   - اعمال فرمول طلایی دسترسی، قانون اولویت استثنا بر دسته‌بندی، تایمر سرور-محور، پایداری در رفرش و قطع فوری دسترسی در پایان مهلت.

## ۴. دستورات پرکاربرد محیط توسعه

```bash
# رفتن به پوشه بک‌اند
cd backend

# اجرای تست بیلد و کامپایل
go build ./...

# اجرای وب‌سرور Fiber v3
go run cmd/server/main.go

# فرامین مایگریشن دیتابیس
go run cmd/migrate/main.go up
go run cmd/migrate/main.go down
go run cmd/migrate/main.go version
```
